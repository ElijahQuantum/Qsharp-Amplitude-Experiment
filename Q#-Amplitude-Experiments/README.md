Goal of experiment : 
-Can i bias one quantum state using rotation gates?

---
Hypothesis :
-My hypothesis is that as i increase the rotation angle i also
  increase the probability of measureing that one state

---
Conclusion :
-The Ry and Rx rotation gates change the amplitude of a qubit.
 As the rotation angle increased one measurement be more likely then the others.
 This demonstrates that rotating a qubit changes it's probability.
